安静的一页，背后是几条笨功夫

没有推荐流、没有热搜、不联网。打开就是今天的诗，翻页只到「今天」为止。

日期就是种子

以 1960 年元旦为起点逐日往前推，当天的日期做随机种子。同一台设备、同一天， 永远是同一首；换手机也一样。

作者不连庄

先挑诗人，再从名下抽一首诗，七天内同一位作者整位跳过（可调 不限 / 3 / 7 / 14 / 30 天）。 语料按作者排，不然会连着好几天都是温庭筠。

节日节气应景

清明、中秋、立秋当天，用节日名字在全库检索，题目命中的优先，其次诗句； 全库都没有，就悄悄回到平日的作者轮换。

打开即见诗

首屏画完之后，后台把往后三天的诗算好存进本地库。下次启动只读一条缓存、按 id 取一首诗： 0.03ms，现算要 27–75ms。

九万首在包里

一个 SQLite 数据库随应用发布，题目、作者、诗句全文检索，简体繁体双写。 飞行模式、地铁、山里，一样翻得到。

纸墨双主题

宣纸底、朱砂印，配一个夜读用的深色。跟随系统，也可以自己钉住； 应用图标就是那枚印章。

白居易 · 问刘十九
一

一天一首，不赶时间

打开就是今天的诗：日期、农历、干支年，题目、朝代与诗人，正文一句一行。 顶栏箭头或左右滑动能翻看前后几天 —— 到今天就停，不会翻到还没到的日子。

  • 作者冷却：先挑诗人再挑他的诗，冷却期内的作者整位跳过；诗人不够多时自动退化成轮流。
  • 应景优先：节日与节气当天先按名字检索（《元日》《清明》《中秋月》…），同一天永远同一首，来年换一首。
  • 隔夜预取：往后三天的诗提前算好写进本地 KV，下次启动只读缓存。
  • 滑动翻页：横向手势才接管，竖向永远留给滚动 —— 上下滚诗不会被吃掉。
二

一页纸，怎么读由你

正文可在系统字体、宋体（衬线，近刻本）、楷体之间切换；字号 10–24 号用滑块调， 题目、作者、列表按基准等比缩放。排版可横排，也可竖排 —— 仿古籍「一行一列、自右向左」。

  • 竖排：原文一行即一列，逐字竖直堆叠，从最右一列读起；行内空白换成全角，标点隐去时也占整格。
  • 标点：保留原文，或把每个标点原位换成空格（连着的「」，不合并）—— 只影响显示，复制与朗读仍是原文。
  • 简繁：每首诗同时存简体与繁体正文，检索两列都匹配，朗读、复制跟着切换。
  • 朗读：系统 TTS 念题目、作者、正文，慢 / 标准 / 快三档；设备没有语音引擎时入口整段收起。
三

把一首诗，排成一张笺

一键成笺：题目、作者、正文、出处，底部一行日期、农历，若当天是节日或节气， 末尾还会多一枚小红印。存进相册「每日诗词」，随即弹出系统分享面板。

  • 版式固定：卡片不跟夜间模式，导出给别人看永远是宣纸色。
  • 局部调整：卡片页可单独调字号、简繁、空白断句，只改这一张，不动阅读设置。
  • 记得上次：用字、标点、字号会记住上次的选择，下一张直接沿用。
四

喜欢的，收在一处

读到合意的按一下「收藏」，收藏页就把它们排好队 —— 题目、作者、首句一目了然， 点进去还是同一页详情。标题右边那只奖杯，就是诗词挑战的入口。

  • 存在本机：随包的 SQLite 里，不联网也不上传。
  • 换库不丢：语料升级后按「题目 + 作者 + 首句」逐条写回。
  • 也能出题：收藏本身就是挑战题源，不足四首时入口禁用。
  • 读过多少天：累计读诗天数记在设置页的「数据」里。
五

十四部集子，随心翻

点开集子就是它的全部作品，右上角两个入口：「按作者」，词集还有「按词牌」。 两张表同一个样子 —— 首字母 A–Z 分组，右侧字母条直达，同一字母下作品多的在前。

  • 作者：全唐诗 3,650 位，按姓氏读音算首字母（曾、单、仇、查、乐 不会排错），「佚名」统一进「其他」。
  • 词牌：全宋词 884 个，最多的浣溪沙 817 首；「别名・正名」的写法也会归到正名。
  • 预统计：作者 / 词牌统计在建库时算好、写进随包 JSON，页面打开即渲染，不跑 GROUP BY。
  • 全文检索：题目、作者、诗句都能搜，简体繁体输入都命中。
六

十道填空，考考记性

从「我的收藏」或任意一部集子里抽十首，每首挖掉一句，四选一填回去 —— 干扰项按字数挑，看着都像。答完当场出分、回顾错题。

  • 日期种子：同一天、同一来源出同一份题；想换一份，重开一局。
  • 只给评价：评级是一句话（加油 / 及格 / 优秀 / 诗仙下凡），分数线不上界面。
  • 战绩：用时、答对数、时间与来源，留最近 20 局。
  • 题源：我的收藏或任意集子，池子不足十首就一首出多题。
七

该藏的藏，该调的调

每日推送、正文字体、外观、朗读语速、数据都在一处。每日精选是一个多选框： 勾了全唐诗，5.7 万首就全是候选。

  • 每日精选：至少留一部；诗词库卡片上的「每日精选」小字跟着它变。
  • 推送方式：经典轮换 / 应景优先。
  • 作者间隔：不限 / 3 / 7 / 14 / 30 天。
  • 正文字体：字体、排版、字号、标点、简繁，带实时预览。
八

语料从哪来

十四部集子共 95,435 首。主体取自开源的 chinese-poetry；乐府诗集从中文维基文库抓一百卷， 宋词三百首取自古文岛，毛泽东诗词由存档页解析。繁体保留语料原文，简体由 OpenCC 转写。

每日池只收「选本」：唐诗三百首、千家诗、宋词三百首、诗经、楚辞、花间集、 南唐词、纳兰性德词、曹操诗集。乐府与毛泽东诗词不进池 —— 郊庙乐章和残篇联句不适合当每日一诗。

九

怎么做的

一个 Expo 应用，一条 just 命令从语料走到安装包。没有服务端，所有计算都在本机。

框架
React Native 0.86 · Expo SDK 57 · expo-router（Stack + NativeTabs）
存储
expo-sqlite，内置库走 assetSource，离线可用
农历
lunar-javascript：节气、节日、干支换算
作者索引
pinyin-pro：姓氏多音字、首字母与全拼排序
朗读
expo-speech：系统 TTS，不打包语音包
卡片
react-native-view-shot + expo-media-library + expo-sharing
挑战
纯函数出题（mulberry32 定种子）+ meta KV 存战绩
构建
Node ≥ 22 的 node:sqlite、OpenCC-js、Python / Pillow（图标）
十

装上就读

语料在安装包里，装完不用联网。Android 可以直接装 Release APK；iOS 需要 macOS 自签， 或者用 EAS 云端签名。

Android

Release APK，约 70MB（大头是随包语料），本地 debug.keystore 签名，可直接覆盖安装。 装到设备上用 adb：

adb install -r dist/daily-poetry-*.apk 下载 APK

iOS

只能在 macOS 上本地打包（未签名，需自签后安装），或者在 Windows 上用 EAS 云端签名出包。

just ipa # macOS：未签名 .ipa just ipa-eas # 任意平台：EAS 云端签名 查看构建说明

自己构建

前置只要 git、Node ≥ 22.5、npm、just；语料脚本会自动抓取并建库。

git clone https://github.com/freewu/daily-poetry cd daily-poetry just init # 装依赖 → 下语料 → 建库 → 生成图标 just start # Expo dev server just apk # 出离线 APK GitHub

代码以 MIT 许可开源；语料版权归原作者与整理方（chinese-poetry、中文维基文库、古文岛）， 仅供学习与个人阅读。问题与新功能请提到仓库 issue。
